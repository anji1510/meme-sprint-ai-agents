A meme about AI agents building games and apps: a robot agent ships a game in minutes, the floor doesn't work, but it calls it a feature.

## Run it

```sh
node main.ts
```

The program copies the pre-rendered meme (entry.png, 1024x1024) to $MAKEFUN_OUTPUT_DIR/entry.png (default /output).
